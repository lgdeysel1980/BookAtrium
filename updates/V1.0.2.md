# BookAtrium V1.0.2

Version: 1.0.2  
Release Date: 11/08/2026

## Release Summary

BookAtrium 1.0.2 focuses on audiobook chapters you can edit and keep, more accurate Amazon and Audible metadata, a leaner plugin system (including much smaller official plugins), a simpler path for third-party plugin authors, and a noticeably smaller install. Web Update for a single book now uses the same Jobs progress window as a multi-book update, and the standalone web server asks which library to open before it starts.

## New & Improved

- **Edit Audiobook Chapters.** Audio Info now includes a Chapters tab and an Edit Chapters window. You can change titles and start/end times, add or remove chapters, reload from the file, and save. Where the audio format allows it, chapters are written into the file itself; otherwise they are kept in the BookAtrium library record.
- **Audible.co.uk metadata.** A new official metadata source searches Audible.co.uk for title, authors, narrators, duration, series, cover, publisher, language, and tags. Audible ASINs in BookAtrium now open Audible.co.uk.
- **Amazon Audiobook ASIN.** Book Editor (desktop and web) can store a separate Amazon audiobook ASIN alongside Kindle and Audible identifiers, so ebook and audiobook editions are not mixed up.
- **Standalone web server startup.** Launching the standalone web server interactively now prompts for port, library database, and whether to open a router port (UPnP) before the server starts.
- **Book format on/off for watched folders.** On the Book Formats settings tab you can enable or disable each extension. Only enabled formats are picked up by watched-folder import.
- **Conversion profile options.** Custom conversion profiles can be edited in Settings under Look & feel, Heuristic processing, Page setup, and Table of Contents. Built-in profiles stay read-only; duplicate a profile to customise it.
- **Syncfusion 34.2.2.** BookAtrium’s Syncfusion libraries (desktop UI, PDF, Blazor web UI, and HTML-to-PDF) are updated to 34.2.2.

## Plugins

- **Much smaller official plugins.** Shared code used by Amazon, metadata, and conversion plugins is kept with BookAtrium itself instead of being copied into every plugin folder. Most official metadata plugins are now a single small plugin file (typically well under 200 KB each) plus their settings, instead of carrying large duplicate libraries.
- **Leaner third-party plugin packages.** When you pack a community plugin, BookAtrium only includes your plugin and the third-party libraries it actually needs. Host libraries and PDF/browser runtimes that BookAtrium already provides are not duplicated into the package.
- **Simpler plugin authoring.** The `bookatrium-plugin` tools create, validate, test, and pack plugins against Plugin API 2.1. You edit one plugin class, and packing generates the package metadata for you—no hand-written package file required. Guides cover store, metadata source, author metadata, reader, writer, conversion, and device plugins.
- **Official Amazon metadata sources** (all regional Amazon book sources) are version **1.0.6**.
- **Official Audible.co.uk** metadata source is included (version **1.0.0**).
- **Amazon US Kindle Store** remains available for searching Kindle listings (version **1.0.5**).
- **PDF conversion output** plugin is version **1.0.1** and uses BookAtrium’s shared HTML-to-PDF engine instead of bundling its own browser runtime.
- Official plugins are managed by BookAtrium and are not overwritten or removed through the community plugin update flow.

## Audiobooks

- Extract or generate chapters from an individual audio file on the Files tab. The work runs in the Jobs window so you can keep using BookAtrium. Closing that window does not stop the job.
- Saving other book metadata no longer silently drops existing audiobook chapters. Chapters already in the file are kept first; library-stored chapters are used only if the file has none.
- Chapter changes that can be embedded are written with a lossless copy of the audio (the sound itself is not re-encoded).
- Audio Details has been renamed **Audio Info**, with separate Details and Chapters sub-tabs.
- Cover preview in Book Editor sizes square audiobook artwork without stretching it to a tall ebook frame.
- The web library can show audiobook chapters. Editing chapters remains on the desktop Book Editor.

## Metadata & Conversion

- Amazon metadata search better distinguishes Kindle, print, and audiobook formats and prefers the matching edition when you search from an audiobook or an ebook.
- Narrator and author names from Amazon and Audible no longer pick up site chrome such as “see all”, “N more”, or role prefixes.
- Web Update uses the correct ASIN type for the source: Kindle ASIN for Amazon ebook search, Amazon audiobook ASIN for Amazon audio, and Audible ASIN for Audible.co.uk.
- In Book Editor, searching by ASIN or title still happens in the editor itself and does not open the library Jobs window.
- Official metadata readers and writers continue to cover common ebook and audio formats, with shared formatting support kept in BookAtrium so individual plugins stay small.
- Conversion input and output plugins for common formats remain available; PDF conversion uses the updated Syncfusion HTML-to-PDF engine shipped with BookAtrium.
- New watched folders default to **automatic import** instead of waiting for Import Plan review. Use Toggle Mode on a folder if you still want assisted review.
- Automatic import can include files that BookAtrium will convert, not only formats that import with no conversion.
- Automatic import no longer refuses to run just because duplicate handling is set to Ask. Unsupported or unreadable files are left in Pending for review.
- Watched-folder import only considers formats enabled on the Book Formats tab.

## Web Server

- **Web Update** for one selected book now uses the same Jobs progress flow as updating several books (desktop and web). If no book is selected, Web Update opens a web search to add a book instead of implying a single-book update.
- Desktop Settings no longer offers a web-server hosting-mode dropdown. The desktop app uses the embedded web server; the standalone web-server executable is started separately.
- Turning on **Open router port (UPnP)** now actually requests the port mapping when the embedded or standalone web server starts, and removes it when the server stops.
- Embedded and standalone web hosting share one set of web static files in a desktop install, so the web UI is not stored twice.
- The web UI ships only the Syncfusion theme BookAtrium uses, instead of a large unused theme collection.

## Performance & Installation

- **Smaller desktop install.** Unused Syncfusion UI packages and an unused DevExpress dependency were removed. Web theme files that BookAtrium never uses are no longer shipped. The Chromium/HTML-to-PDF runtime and official plugins are stored once for the desktop app (not duplicated inside the nested web server). Together these changes substantially reduce install footprint compared with earlier 1.0.x builds.
- Libraries open on an updated database schema that stores audiobook chapter data; BookAtrium migrates existing libraries automatically.
- SMTP accounts and email/Kindle/ereader destinations are added and edited in dedicated windows instead of cramped inline fields.
- The Files tab no longer offers Calculate MD5. Use Extract chapters on an audio file row when you need chapter work.

## Fixes

- Saving book metadata no longer clears audiobook chapters that were already present.
- Amazon and Audible contributor fields are cleaned so “see all”, “N more”, and similar labels are not stored as narrator or author names.
- Turning on **Open router port (UPnP)** now maps and unmaps the port correctly for both embedded and standalone web servers.
- If the updater component (`BookAtriumUpdater.exe`) is missing from an installed copy, BookAtrium asks you to repair or reinstall instead of showing a developer-only message.
- Cover preview no longer stretches square audiobook artwork into a tall ebook frame.

## Removed or Changed Behaviour

- **Watched folder default:** new folders import matching enabled formats automatically. Existing folders keep the mode you already chose until you change it.
- **Web server default:** new settings default to embedded hosting. A previous Standalone default in desktop Settings is no longer used there.
- **Web Update (single book):** the old one-book web-search dialog for library Web Update is replaced by the Jobs update flow. Book Editor ASIN/title search is unchanged.
- **Identifier labels:** “Amazon Audio” is now **Audible**. Amazon audiobook editions use **Amazon Audiobook**.
- **Calculate MD5** has been removed from the Files tab.

Chapter editing, extraction, and embedding need FFmpeg, as with chapter extraction in 1.0.1. DRM-protected or rewrite-unsafe audio files are not overwritten; those chapters stay in the library record only.
